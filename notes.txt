String Interning - This process of ensuring only a single copy of a unique value of a string exists in memory is call string interning.
                 - string is a primitive data type in JavaScript, and when we create a string literal like "JavaScript", it is stored in a special area of memory called the string pool. If we create another string literal with the same value, like str1 = "JavaScript", it will point to the same memory location as str, instead of creating a new string object. This is known as string interning.
                 - for memory optimization
                 - it make string comparison is faster
